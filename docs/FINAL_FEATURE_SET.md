# Final Feature Set

> Auto-generated by `scripts/10_generate_feature_docs.py`. Machine-readable version: `config/final_features.json`.

**30 features** (9 categorical, 21 numeric), selected from 185 candidates.

**Target:** `y_nonsusceptible` — 1 = non-susceptible (Resistant or Intermediate), 0 = susceptible.

**Selection method:** The final feature set is the candidate set with the highest PR-AUC on the held-out validation patients, with `antibiotic` and `antibiotic_class` force-retained because a single unified model cannot identify which agent it is scoring without them. The organism-blind arm is excluded from the contest because it is a measurement, not a candidate.

## Why each was selected

**`antibiotic_is_oral`**

> Separates the older, narrower oral agents from parenteral broad-spectrum ones.

**`antibiotic`**

> Identity of the agent is the single largest driver — base resistance rates differ by an order of magnitude between agents.

**`organism_clean`**

> Susceptibility is overwhelmingly organism-specific. Removing it costs 0.11 PR-AUC (see the organism-blind ablation).

**`antibiotic_class`**

> Cross-resistance is organised by mechanism, so class lets a rare agent borrow structure from a common one in the same class.

**`prior_same_abx_nonsusc_rate`, `prior_res_same_org_abx_days_since`, `prior_same_org_nonsusc_rate`, `prior_same_abx_n_nonsusc`, `prior_same_org_days_since`, `prior_res_n_events_1095d`, `prior_same_org_n_tests`, `prior_res_same_org_abx_n`, `prior_med_class__Fluoroquinolone__90d`, `prior_med_n_drugdays_180d`, `prior_med_n_drugdays_30d`, `prior_res_same_abx_n`, `prior_med_n_broadspectrum_drugdays_90d`, `prior_med_class__Folate_pathway_inhibitor__90d`, `prior_med_same_class_exposed_365d`, `has_prior_med_history`**

> Prior resistance and prior exposure are the classical drivers of subsequent resistance and are the strongest non-organism signals in this dataset.

**`antibiotic_subclass`**

> Separates 1st- from 3rd-generation cephalosporins, which behave very differently against AmpC organisms.

**`order_year`**

> Resistance prevalence drifts substantially across the 2007-2024 span; the year lets the model track that trend.

**`antibiotic_aware`**

> Correlates with how heavily an agent has been used and therefore with population-level resistance.

**`organism_group`**

> Encodes intrinsic-resistance structure: gram-negatives are impermeable to glycopeptides regardless of species.

**`antibiotic_is_urinary_only`**

> These agents have distinctive resistance profiles and are only tested on urinary isolates.

**`culture_description`**

> Resistance prevalence and the tested panel both differ sharply by site.

**`gender_code`**

> Retained as an anonymous covariate; urinary-tract infection epidemiology differs strongly by sex.

**`organism_genus`**

> Lets rare species inherit their genus's typical profile.

**`organism_morphotype`**

> Mucoid Pseudomonas and small-colony-variant S. aureus are distinct clinical phenotypes; observed at identification, so not leakage.

**`is_species_level`**

> A genus-only identification is itself informative about specimen quality and organism rarity.

## Preprocessing applied

| Feature type | Transformation | Why |
|---|---|---|
| Categorical (9 features) | Ordinal codes learned on the training fold; unseen categories map to `-1` | Gradient-boosted trees split on ordered values and treat an unseen code as its own branch. One-hot encoding of `organism_clean` alone would add 245 sparse columns. |
| Numeric counts | Missing filled with 0 during dataset construction | A missing prior-exposure count is a true zero: no such event was recorded. |
| `*_days_since` | Left as NaN | 'Never happened' is not the same as 'happened zero days ago'. The tree routes NaN down its own branch. |
| Laboratory values | Left as NaN | Missingness is informative — an unordered procalcitonin means severe sepsis was not suspected. |
| Nothing | No scaling, no imputation for the tree models | Scale-invariant learner; imputing would destroy the missingness signal. The linear baselines in Phase 7 use a separate pipeline with median imputation and standardisation. |

## What did NOT make the final set, and what that tells us

**No laboratory value survived selection** (2 lab features in the final set). This is a substantive finding, not an oversight:

* Laboratory results are only available for 46.2% of culture orders, so a lab-based split is fitted to under half the data.
* The lab panel measures how *unwell* a patient is — inflammatory and renal markers. Whether an isolate is resistant to a given agent is driven by that patient's antibiotic and resistance history and by the organism itself, not by how high their white cell count is.
* The lab block is also internally redundant: 35 features were removed by the correlation filter alone, most of them Q25/median/Q75 triplets of the same analyte.
* The full-feature arm, which *does* include every lab value, scores 0.7480 against 0.7615 for the selected set — so including them measurably hurts.

**Age did not survive either.** `age_band_ordinal` ranked outside the top 30 by XGBoost gain. Age correlates strongly with comorbidity and prior antibiotic exposure, and once those exposure features are in the model, age adds little independent information.

Both exclusions are empirical results from held-out validation patients, and both are reversible: the full-feature arm is retained in `13_RESULTS/tables/feature_selection_comparison.csv` so the trade-off can be re-examined.
