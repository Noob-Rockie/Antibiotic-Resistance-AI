## 1. What the data can actually support

The label column is `susceptibility` in `microbiology_cultures_cohort.csv`. Its full observed distribution:

| Value | Rows | Share of labelled rows |
|---|--:|--:|
| `Susceptible` | 1,289,258 | 80.249% |
| `Resistant` | 265,071 | 16.499% |
| `Intermediate` | 47,651 | 2.966% |
| `Inconclusive` | 2,670 | 0.166% |
| `Synergism` | 1,932 | 0.120% |
| *(no result — negative culture)* | 634,468 | — |

Two of the five categories are not susceptibility phenotypes: `Inconclusive` (2,670 rows) is an uninterpretable test and `Synergism` (1,932 rows) reports a two-drug interaction assay, not the single-agent phenotype the rest of the column encodes. Both are removed rather than forced into a class they do not belong to (4,602 rows).

## 2. Chosen task

**Primary task — binary classification: Susceptible vs Non-susceptible.**

`Intermediate` is grouped with `Resistant` into a single *non-susceptible* class. This is the standard antimicrobial-stewardship reading: an Intermediate result means the agent cannot be relied on at ordinary dosing, so for the decision the model supports — *is this agent a defensible option?* — Intermediate and Resistant carry the same clinical consequence. Collapsing them also avoids modelling a 2.98% class that is defined by a narrow MIC band around a breakpoint and is the least reproducible category in AST.

| Class | Rows | Share |
|---|--:|--:|
| Susceptible (0) | 1,270,147 | 80.481% |
| Non-susceptible (1) = Resistant + Intermediate | 308,049 | 19.519% |

Positive-class prevalence is **19.52%** — imbalanced, but not extremely so. Handling is documented in `docs/MODEL_EVALUATION.md`.

**Secondary task — 3-class Susceptible / Intermediate / Resistant.** The data does support it (45,162 Intermediate rows), so it is trained and reported as a secondary analysis to show what is lost and gained by keeping the middle category, rather than being asserted as impossible.

## 3. Unit of analysis

One row = **one (culture order x organism x antibiotic tested)** combination. The final table holds 1,578,196 such rows, drawn from 118,749 positive culture orders and 67,008 patients.

A single culture order contributes one row per antibiotic on its AST panel (mean 13.3 rows per order). Which agents appear on the panel is decided by the laboratory, not at random — a structural feature of the data that Section 4 addresses directly.

## 4. Model architecture: three candidate framings, compared

| Approach | How it works | Why it was or was not chosen |
|---|---|---|
| **A. One model per antibiotic** | Train 54 independent classifiers, one per agent. | Rejected as the primary design. The panel is extremely ragged: Ciprofloxacin has 111,321 rows while Cefpodoxime has 9 and Chloramphenicol 12. Two thirds of the agents cannot support an independent model, and nothing is shared between them, so a rare carbapenem cannot borrow from a common one. Retained as a **comparison arm** for the highest-volume agents. |
| **B. Multi-output / multi-label** | One model predicting all 54 agents per isolate simultaneously. | Rejected. The label matrix would be ~76% missing by construction, because each isolate is only tested against the panel the laboratory selected. Multi-output learners require a dense target; the missingness here is informative (panel choice depends on organism and specimen), so masking it would bias the model. |
| **C. Unified model, antibiotic as a feature** | One model over (isolate, antibiotic) rows, with the agent and its class as input features. | **Chosen.** It matches the natural grain of the data, uses every row, shares structure across agents in the same class, and — decisively for the application — it can score *any* agent for a new isolate, which is what a ranked recommendation needs. |

The chosen design is made possible by the antibiotic taxonomy in `src/preprocessing/antibiotic_taxonomy.py`, which gives every one of the 54 agents a class, subclass and WHO AWaRe category so that rare agents inherit structure from their class.

## 5. Splitting protocol

**Primary: grouped by patient.** 53.834% of patients have more than one culture order, so the split is grouped on `anon_id` (train / validation / test = 70 / 10 / 20 by patient). No patient appears in more than one partition. Cross-validation inside training uses `StratifiedGroupKFold` on the same key.

**Secondary: temporal holdout.** The cohort spans 2007-10-09 to 2024-01-31. Resistance prevalence and prescribing both drift over that period, so a second evaluation trains on the earlier years and tests on the most recent ones. This measures the thing that actually matters for deployment — whether a model fitted on the past still works on the future — and is reported alongside the grouped result rather than instead of it.

## 6. Metrics

Accuracy is reported but is **not** the selection metric: predicting "susceptible" for every row would already score 80.5%. Model selection uses:

| Metric | Why it matters here |
|---|---|
| **PR-AUC (average precision)** | Primary selection metric. The positive class (non-susceptible) is the minority and the clinically costly one; PR-AUC is the metric that responds to it. |
| **ROC-AUC** | Threshold-free ranking quality; comparable to the published AMR-prediction literature. |
| **Recall / sensitivity for non-susceptible** | A missed resistance is an ineffective antibiotic given to a patient — the expensive error. |
| **Specificity** | A false resistance call pushes the clinician towards an unnecessarily broad agent, which drives future resistance. |
| **Precision, F1, macro-F1, weighted-F1** | Reported for completeness and for the 3-class secondary task. |
| **Calibration (Brier score, reliability curve)** | The application shows probabilities to a clinician and ranks agents by them. A miscalibrated 0.8 is actively misleading, so calibration is treated as a first-class result, not an afterthought. |

## 7. What this model is not

It estimates the probability that a *laboratory* would call an isolate non-susceptible to an agent. It does not predict clinical cure, it does not account for the site of infection beyond the specimen type, source control, drug penetration, allergy, renal or hepatic dosing, pregnancy, interactions or cost-effectiveness, and it cannot replace an actual AST. Every use of its output in this project is framed as decision support for a qualified clinician who remains the decision-maker.
