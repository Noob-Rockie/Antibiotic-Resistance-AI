## What this system is not

It estimates the probability that a *laboratory* would report an identified isolate as non-susceptible to a given antibiotic. It does not predict clinical cure, it does not prescribe, it does not replace antimicrobial susceptibility testing, and it makes no genomic claims. Every ranked option is a *potential option for clinician review*, and a qualified healthcare professional remains the decision-maker.
