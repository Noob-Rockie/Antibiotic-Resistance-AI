## Explicit non-objectives

These were considered and deliberately excluded, so that their absence is a decision rather than an omission:

- **Autonomous prescribing.** The system has no mechanism to order a drug and must never be given one.
- **Dose calculation.** Even with complete patient data this project would relay the label and leave the calculation to the prescriber. Creatinine clearance is not computed because the dataset has no body weight.
- **Course-cost calculation.** It would require a dose the project does not generate.
- **Genomic prediction.** These datasets contain no genomic data; the module is built and inactive rather than fabricated.
- **Clinical outcome prediction.** The target is a laboratory susceptibility category, not cure or mortality.
- **Drug-interaction checking.** The NLM API for it is retired; showing nothing is better than showing data from an unmaintained source.
- **Paediatric use.** The youngest age band in the data is 18-24 years.
