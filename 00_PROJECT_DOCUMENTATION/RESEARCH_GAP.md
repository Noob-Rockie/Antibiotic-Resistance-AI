# Research Gap

> Auto-generated by `scripts/12_generate_project_docs.py`. Every claim below is backed by a measurement in this project.

Published antimicrobial-resistance prediction work tends to share several methodological weaknesses. This project was built to address each one explicitly, and to show the evidence rather than assert the fix.

## Gap 1 — Leakage is asserted, not demonstrated

**Typical practice.** A sentence stating that leaky features were removed.

**What this project does.** Every candidate pathway is investigated with measured evidence and the verdict published, including one a reader would not think to look for: the resistance phenotype written into the organism *name*. 21,879 rows carry tokens such as `STAPH AUREUS {MRSA}` or `KLEBSIELLA PNEUMONIAE (CARBAPENEM RESISTANT)`. Rows with a vancomycin-resistant token were **100%** resistant to glycopeptides against a 2.83% class baseline — the label, restated in text.

Equally important, the most suspicious table was investigated and **cleared**: the prior-resistance history keys on the index culture order, but every event predates it by at least a day, it matches only 4.13% of rows, and matched rows are 63.7% resistant rather than ~100%. Predictive, and genuinely history.

See [`../docs/DATA_LEAKAGE_ANALYSIS.md`](../docs/DATA_LEAKAGE_ANALYSIS.md).

## Gap 2 — Feature selection is a footnote

**Typical practice.** Train on every column, or cite a single feature-importance plot.

**What this project does.** Seven methods, 8 candidate feature sets compared on held-out validation patients, a feature-count sweep, an organism-blind ablation that quantifies how much of the signal the organism carries (PR-AUC 0.7615 falling to 0.6548), and — the part that is almost never done — a measurement of whether the selection *itself* leaked. Re-deriving the selection inside every cross-validation fold scores 0.75861 against 0.75963 for the globally chosen list: an optimism of +0.00102 PR-AUC, smaller than the fold-to-fold spread.

A finding that would usually be buried: **no laboratory value and no age feature survived selection**, and the full-feature arm scores *worse* than the selected 30.

See [`../04_FEATURE_SELECTION/FEATURE_SELECTION_REPORT.md`](../04_FEATURE_SELECTION/FEATURE_SELECTION_REPORT.md).

## Gap 3 — Random row splits inflate results

**Typical practice.** `train_test_split` over rows.

**What this project does.** 53.8% of patients contribute more than one culture order, and one contributes 175. A random row split would place the same patient — often the same organism, sometimes the same week — on both sides, so the test set would partly measure memorisation. All splits are grouped by patient, asserted by a test.

A **temporal holdout** is reported alongside it, training on the earlier years and testing on the most recent, with patients straddling the cut-off removed from the test side. That is the deployment-realistic number, and it is lower: PR-AUC 0.68597 against 0.76166. It is reported rather than hidden.

## Gap 4 — Explanation stops at a global bar chart

**Typical practice.** One feature-importance figure.

**What this project does.** Exact TreeSHAP, with additivity verified numerically. Per-prediction explanations are rendered in the application in clinical language. The model's **failures** are explained alongside its successes. And a mechanism check verifies that the history features move predictions in the clinically expected direction — the one feature whose SHAP direction disagreed was investigated and shown to be credit-splitting between collinear features rather than a learned shortcut.

See [`../07_EXPLAINABLE_AI/XAI_REPORT.md`](../07_EXPLAINABLE_AI/XAI_REPORT.md).

## Gap 5 — Decision support that quietly becomes prescribing

**Typical practice.** A ranked list presented as an answer.

**What this project does.** The model's probability is never modified by any downstream layer. Clinical guardrails from cited sources (EUCAST/CLSI intrinsic resistance, FDA labelling for site suitability, WHO AWaRe stewardship tiers) **flag and re-order** options; they never delete one, so the clinician sees both what the model estimated and why an option was pushed down. Every option carries the number of training examples behind it. Dosage is quoted verbatim from the FDA label and never computed. The system has no mechanism to prescribe.

## Gap 6 — Panel-selection bias is ignored

**Typical practice.** Treat the AST panel as if it were complete.

**What this project does.** The EDA measures it: only 21.626% of the organism x antibiotic space has any test at all. The model therefore learns the resistance pattern *conditional on being tested*, which is stated as a limitation in the model card rather than glossed over, and it is the reason a unified model that shares structure through antibiotic class and organism group was chosen over independent per-agent models.
