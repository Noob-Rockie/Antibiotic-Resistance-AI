## In one paragraph

When a bacterial culture turns positive, the organism is identified roughly 24 hours before the antimicrobial susceptibility test (AST) result arrives. This project builds an explainable machine-learning system that predicts, during that window, the probability that the laboratory will report the isolate **non-susceptible** to each of 54 antibiotics — then explains each prediction with SHAP, ranks the agents for clinician review behind cited clinical guardrails, and requires a recorded human decision. It is a research prototype and not an autonomous prescribing system.

## What makes it more than a notebook

- **Raw data is never modified.** It is referenced in place, with an MD5 manifest and a verification script.
- **Every published number is generated from a pipeline artefact**, so documentation cannot drift from the data. A consistency audit enforces it.
- **Leakage is demonstrated, not asserted** — including 21,879 rows where the resistance answer was hidden inside the organism *name*.
- **The test partition is read exactly once.**
- **Guardrails flag, never filter.** Nothing is hidden from the reviewing clinician.
- **Dosage is relayed verbatim from the FDA label and never computed; cost is retrieved from CMS NADAC and never estimated.**

## Safety

> This application is a research/clinical decision-support prototype. It does not replace qualified healthcare professionals, antimicrobial susceptibility testing, clinical guidelines, or professional medical judgment. AI-generated predictions and recommendations must be reviewed by an appropriately qualified healthcare professional.
